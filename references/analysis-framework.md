# 分析要点

从聊天数据中识别用户的沟通模式，并穿透到模式背后的心智模型。

模式是"你做了什么"，心智模型是"你为什么这样做"——你用什么框架在看世界、做判断、保护自己。

## 可识别的维度

- **表达模式**：消息长度、句式习惯、铺垫词、连发行为、标点表情使用
- **情感光谱**：情感词汇分布、情感触发器、被压缩的情绪、情感表达的丰富度
- **认知模式**：提问频率和质量、好奇心方向、推理风格、信息密度
- **社交行为**：主动性、回应速度、话题发起权、情感劳动分配
- **防御机制**：幽默防御、免责声明、教学模式、谦虚防御、信息过载、情感压缩
- **自我叙事**：如何讲述自己的过去、重大事件的压缩程度、自我定位

## 分析原则

- 找模式，不是找问题——一个模式在某些情境下是优势，在另一些情境下是限制
- 被压抑的情绪往往比表达出的情绪更有价值
- 优势模式的情境失效分析，和发现弱点一样有价值
- 不要每个维度都凑一个"发现"——数据不足就跳过
- 同时输出"在运作的"和"在限制的"，不要只输出一侧
