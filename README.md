# Self-Iteration

> 从聊天记录中看见真实的自己，然后变好。

---

## 为什么是现在

我们生活在一个奇怪的时代：我们每天发出几十条消息，却很少回看自己说了什么。

你知道自己在社交场合是什么样的吗？你可能会说"我还挺健谈的"或者"我比较慢热"。但这是你**以为的自己**，不是**真实的自己**。

心理学有一个经典问题：人们能在多大程度上准确地认识自己？答案是：**很差**。几十年的研究反复验证了一个现象——人们对自己行为模式的自我报告，和他们的实际行为之间，存在系统性偏差。我们倾向于高估自己的优点，低估自己的盲区，而且对自己的防御机制几乎完全没有觉察。

但今天，我们第一次有了绕过这种偏差的材料：**聊天记录**。

你的每一条消息，都是你当时真实反应的化石——没有经过事后美化，没有经过"我应该怎么说"的过滤。你在对方说"我好累"的时候下意识转移话题，你在分享快乐的时候习惯性往回兜，你在面对脆弱的时候本能地用段子兜底——这些你可能从来不记得，但聊天记录都记得。

Self-Iteration 就是做这件事：**用你自己的行为数据，照见你自己。**

---

## 创作初心

大多数自我提升的起点是"我想改掉拖延"或"我想变得更自信"。但这些目标本身就是问题——它们基于你对自己的假设，而这些假设很可能是错的。

你觉得自己"不够自信"，但数据显示你在对话中其实非常主导。你觉得自己"挺会聊天的"，但数据显示你 41 天里问过真正的问题只有 14 个。你以为你需要改 A，但你的数据指向 B。

Self-Iteration 的出发点不是"帮你改掉什么"，而是**先让你看见**。

看见你在对话中是什么样的。看见你的情感表达是丰富还是贫瘠。看见你是在倾听还是在输出。看见你的优势在什么情境下会变成限制。看见你的防御机制是如何保护你、同时又如何阻止你被看见的。

看见之后，改变自然会发生。

## 产品价值

### 它能做什么

上传聊天记录（支持 WeFlow、微信、Telegram、WhatsApp、Discord 等格式），AI 会基于你的实际沟通行为，输出一份完整的自我洞察：

- **沟通模式图谱**：你在对话中的核心模式是什么？什么在运作？什么在限制你？
- **心智模型穿透**：不停在"你做了什么"，而是理解"你用什么框架在看世界"
- **情境失效分析**：你的优势模式在什么情境下可能失效？
- **行动建议**：具体的、可执行的提升方向，不是"你应该更开放"，而是"下次对方说 X，试试做 Y"

### 它不是什么

- **不是性格测试**：不基于问卷和自我报告，基于你的实际行为数据
- **不是心理评估**：不能替代专业心理咨询
- **不是关系分析**：分析对象是你自己，不是聊天中的其他人
- **不是一次性的报告**：支持迭代追踪——定期导出新的聊天记录，看看你的模式有没有变化

### 价值适用于所有人

- **问题很多的人**：发现你没意识到的盲区，但不会打击你——同时告诉你什么在运作
- **问题很少的人**：不会变成挑刺——而是提供深层洞察和情境优化
- **已经很优秀的人**：理解你的心智模型，找到优势模式的失效边界

## 产品哲学

### 行为数据 > 自我报告

你告诉别人"我是一个很好的倾听者"，但你的聊天记录显示你在 41 天里只问了 14 个问题。你告诉自己"我挺乐观的"，但你的情感词汇只有"还行"一种天气。

人会美化自己，数据不会。这不是说数据比你更了解你——而是数据提供了一个你无法从内部获得的视角。

### 模式没有好坏

你的"段子防御"在保护你——它让你在社交中永远安全。但同样的模式也在阻止你——它让你的话永远到不了底，让你的重量永远落不下来。

Self-Iteration 不预设"你有问题需要修"。它只识别模式：什么在运作，什么在限制你，什么情境下你的优势会失效。然后由你自己决定要不要调整。

### 理解比改变重要

很多人想要的是"改变"——改掉拖延、改掉社恐、改掉情绪化。但没有理解的改变是盲目的。你不知道自己为什么这样做，你就不可能真正改变它。

Self-Iteration 的顺序是：**看见 → 理解 → 改变**。看见你的模式，理解模式背后的心智模型，然后改变会自然发生——因为当你真正理解了自己，你不需要"努力改变"，你会自然地做出不同的选择。

### 诚实边界

- 分析基于你发送的文字，不包含语音、表情包、未发出的草稿
- 聊天记录只是你生活的一个切面，不代表你的全部人格
- 你在不同关系中的沟通模式可能不同，此分析反映的是特定关系中的模式
- 不能替代专业心理咨询或心理评估

## 快速开始

### 安装

下载 `self-iteration.skill` 文件，放入你的 agent 技能目录。

### 使用

1. 导出你的聊天记录（推荐 [WeFlow](https://github.com/nicepkg/WeFlow)，支持微信记录导出）
2. 将导出文件发送给你的 AI agent
3. AI 会自动解析并输出洞察

### 支持的格式

| 格式 | 来源 | 说明 |
|------|------|------|
| WeFlow JSON | 微信 | `isSend` 字段自动识别用户本人 |
| 微信 TXT | 微信 | "发送者: 消息内容" 格式 |
| 微信 CSV | 微信 | 带表头的 CSV 格式 |
| Telegram | Telegram | `result.json` |
| WhatsApp | WhatsApp | 聊天导出 `.txt` |
| Discord | Discord | DiscordChatExporter 导出 |
| 通用文本 | 任意 | "发送者: 消息内容" 格式 |
